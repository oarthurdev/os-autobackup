**Project Name:** `Ubuntu AutoBackup`

**Project Description:**  
Create a full-featured system that performs **automatic daily full backups** of a remote Ubuntu VPS. The system must include both a **CLI tool** and a **Web interface (dashboard)**. The backup must include the **entire system**, including files, databases, and configurations.

## 🎯 Project Goals
- Automatically perform full system backups of a remote Ubuntu VPS every 24 hours.
- Store backups securely on **Google Drive**.
- Compress backup data as `.tar.gz`.
- Encrypt the backups.
- Provide logs for each backup operation.
- Offer both CLI-based and Web-based access for management and status monitoring.

## 🔧 Target Platform
- Web application (for remote control via browser)
- CLI tool (for manual or automated terminal use)

## 🌐 Operating Environment
- Online: the system must operate remotely to back up one or more Ubuntu servers via SSH.

## ☁️ Hosting & Storage
- Backups must be uploaded and stored on **Google Drive** using Google Drive API.
- Secrets and credentials must be securely stored using environment variables or `.env` files.

## 🖥 Interface Style
- **CLI Tool**: Command-line interface with simple, clear commands for status check and manual backup execution.
- **Web Interface**: Minimalist and responsive dashboard in **Portuguese**, showing:
  - Backup history with status (Success/Fail)
  - Download links to `.tar.gz` files
  - Error logs and timestamps
  - "Force Backup Now" button

## 🧱 Functional Requirements
- Schedule daily backups using a task scheduler (e.g., cron or Python scheduler).
- SSH into the remote VPS securely and create a full archive.
- Compress the backup with `.tar.gz`.
- Encrypt the archive using a symmetric key or public key (e.g., AES or GPG).
- Upload the encrypted file to Google Drive using official API libraries.
- Log every operation (start time, end time, size, errors) into a local or cloud-based log.
- Web interface in **Portuguese**, CLI in **English**.

## 📤 Expected Outputs
- Daily encrypted `.tar.gz` backup files stored on Google Drive.
- Log files with timestamp and status of each operation.
- Web interface displaying logs and backup status.

## 🗣 Language Preferences
- **Application Interface (Web UI):** Portuguese
